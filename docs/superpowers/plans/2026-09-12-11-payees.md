# Plan B (v1.1) — Payees Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make payees first-class — a `Payee` entity (name, optional **default category**), an optional `payee_id` on transactions, an autocomplete picker in the transaction form, sensible demo payees, and a management panel. When a transaction gets a payee that has a default category and no category of its own, the payee's default category is applied — the small convenience that makes categorizing fast.

**Architecture:** Follows the established finance pattern and mirrors Track A (categories) exactly — model + migration + service[flush-not-commit, events, workspace-scoped] + thin router + hooks/panel. One migration `0007`. Payees seed for demo data only (unlike categories, no per-workspace defaults — a fresh workspace starts with no payees; you add them as you go).

**Tech Stack:** no new deps.

## Global Constraints

- Follow `docs/CONVENTIONS.md` (layering, transaction contract [services flush, routers commit], §3 StrEnum+CHECK where relevant, §4 money minor units, §6 keyset pagination, §7 events/allowlists, §8 testing, §9 frontend token system). Spec/roadmap: `docs/superpowers/plans/2026-09-12-00-v1.1-roadmap.md` (Track B, depends on A).
- Workspace-scoped (D7) + `is_demo` on `payees`. Events published for audit/activity. Conventional commits, **no trailers**. Baseline at branch start: backend 327 pytest, web 541 vitest green.
- `payees.default_category_id` FK → categories `ON DELETE SET NULL` (deleting a category never destroys a payee). `transactions.payee_id` FK → payees `ON DELETE SET NULL` (archiving/deleting a payee never destroys a transaction).
- Unique `(workspace_id, name)` — a payee name is unique within a workspace (case-sensitive, mirroring categories; no normalization beyond trim).

### Task 2: PayeeService + endpoints + wire payee_id (with default-category apply) into transactions

**Files:** Create `api/src/pecunia/services/payees.py`, `api/src/pecunia/api/payees.py`; modify `api/src/pecunia/services/transactions.py` + `api/src/pecunia/api/transactions.py` (accept/validate/return `payee_id`, `?payee_id=` filter, default-category apply), `api/src/pecunia/main.py` (mount); tests `api/tests/test_payees.py` (+ extend transaction tests).

**Interfaces:**
- `PayeeService(db)`: create/list/get/update/archive (mirror `CategoryService`; events `payee.created/updated/archived`; add to `Actions`). Scoped via `scoped_select`/`get_scoped`. `create`/`update` validate `default_category_id` (if given) belongs to the workspace (422 if foreign). List keyset by `created_at`.
- Endpoints `/api/v1/payees` (require_workspace, require_initialized): POST 201, GET (list), GET/{id}, PATCH/{id}, POST/{id}/archive. `PayeeOut` = {id,name,default_category_id,archived_at,is_demo,created_at}.
- Transactions: `TransactionIn`/`Update` accept optional `payee_id`; the service validates it belongs to the workspace (404/422 if foreign); `TransactionOut` returns it; list accepts `?payee_id=`. **Default-category apply:** on transaction create, if `payee_id` is set, `category_id` is NOT provided, and the payee has a `default_category_id`, set the transaction's `category_id` to the payee's default. Explicit `category_id` (including explicit null) always wins; the apply is create-only (never overrides on update). Document this in the service.

- [ ] **Step 1: Failing tests:** create a payee → 201 + listed; a payee with a `default_category_id` from another workspace → 422; a transaction created with a foreign `payee_id` → 404/422; a transaction returns its `payee_id`; listing `?payee_id=` filters; a transaction created with a payee that has a default category and no explicit category inherits that category; an explicit `category_id` overrides the payee default; update never auto-applies; archiving a payee leaves its transactions (payee_id nulled per SET NULL — assert).
- [ ] **Step 2–4:** implement mirroring categories/transactions; keep parity + full suite green. **Step 5:** commit `feat: payee service, endpoints, and transaction wiring with default-category apply`.
