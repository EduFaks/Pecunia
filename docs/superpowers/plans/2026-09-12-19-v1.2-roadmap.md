# Pecunia v1.2 — Roadmap (charts, contacts, subscriptions, + UX)

**Approved 2026-09-12** (owner Q&A). v1.1 (re-skin, A–E, Planned, Portfolio, Loans, F) is merged. v1.2 is a batch of enhancements, each its own spec→plan→subagent-driven build→whole-branch review→merge, in dependency order. Migrations continue from 0013.

## Locked decisions (from owner)
- **Vibrant color travels to charts AND category chips** (refresh the category palette); rest of the UI stays monochrome minimal-tech. Charts use **shadcn charts** (Recharts).
- **Loan ↔ transaction links BOTH ways** (attach an existing tx to a payment; and "apply a tx to a loan" from the transaction).
- **Payee → Contact: FULL rename** — a party (person **or** company), usable on any transaction (in or out), with an avatar and a per-contact **overview**. `payee`→`contact`, `payee_id`→`contact_id` app-wide (pre-1.0, demo-only — clean).
- **Subscriptions: separate new domain** — name, uploaded **logo**, cost, billing cycle, next renewal, optional links; monthly + annualized totals and upcoming renewals.
- **Images: upload a small image stored locally** (offline, self-hosted, no external fetch) — ONE mechanism reused by contact avatars + subscription logos, with a monogram+color fallback.
- **Sidebar: grouped section headers** — Overview / Money / Net worth / Plan (Activity + Settings pinned bottom).
