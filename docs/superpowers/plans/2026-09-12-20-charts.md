# Track G (v1.2) — shadcn Charts + Vibrant Palette Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the hand-rolled SVG charts with **shadcn charts** (Recharts + a token-driven theme layer) and give data-viz a **vibrant** categorical palette that reads on the near-black ground — including refreshing the **category palette** so chips + the spending-by-category chart pop. The rest of the UI stays monochrome minimal-tech; charts are the sanctioned vibrant exception.

**Architecture:** Add `recharts`; vendor a trimmed shadcn `chart` primitive (`ChartContainer`/`ChartTooltip`/`ChartTooltipContent`/`ChartLegend`/`ChartLegendContent` + `ChartConfig`) adapted to Pecunia's Tailwind v4 + `--pc-*` tokens. New vibrant `--chart-1…8` tokens (dark-tuned) drive both the charts and a refreshed category `PALETTE` (api + web, kept identical). Value-movement stays emerald/coral (income/spend), NOT categorical.

**Vibrant palette (concrete, legible on `#0a0a0b`; distinct from emerald `#4fb286` / coral `#e0695f`):**
`--chart-1:#22d3ee` (cyan) · `--chart-2:#a78bfa` (violet) · `--chart-3:#fbbf24` (amber) · `--chart-4:#fb7185` (rose) · `--chart-5:#38bdf8` (sky) · `--chart-6:#a3e635` (lime) · `--chart-7:#fb923c` (orange) · `--chart-8:#e879f9` (fuchsia). The category `PALETTE` becomes these same 8 hexes (in this order).
