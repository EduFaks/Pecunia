# Re-skin — Minimal-Tech Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace Pecunia's V1 "editorial" identity (near-black+bronze accent, Fraunces serif, hand-drawn ledger flourishes) with the owner-approved **minimal-tech** identity (Linear/Vercel/Raycast vibe): near-black ground, dark-grey surfaces, a single **white** accent, a **system typeface**, no decorative flourishes. Because every component draws from `--pc-*` tokens, this is largely a centralized token+font swap that re-themes the whole app at once — plus the one real code change a white accent forces (text/icons that sit *on* the accent must flip dark), removing the hand-drawn decorations, and refreshing the category color palette for the new ground.

**Architecture:** `web/src/styles/tokens.css` (token values) + `global.css` (@theme font + font imports) carry the swap. A new `--pc-on-accent` token fixes contrast on the now-white accent. The api+web category `PALETTE` is refreshed together. No behavior changes; the test suites stay green (they assert classes/behavior, not hex).

**Tech Stack:** removes the `@fontsource-*` deps (system fonts need no packages).

## Global Constraints

- Follow `docs/CONVENTIONS.md` §9 — after this lands, update §9's palette/font/motion prose to the new identity in the same change. Keep every token NAME identical (only values change) so all components re-theme automatically; keep it tokens-only (no raw hex introduced).
- **Keep both suites green:** `cd api && uv run pytest` (326) and `cd web && npm run test` (550). A test asserting a specific old hex or a Fraunces reference is updated to the new identity, not deleted.
- Money still integer minor units; muted green/red retained ONLY for value movement (they must read on near-black); everything else monochrome. Conventional commits, **no trailers**.
- Node 20 via nvm; `cd web && source ~/.nvm/nvm.sh` if needed.
